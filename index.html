Almost ready — one tiny setup step!

Scribblish keeps rooms in a free Firebase database, and this copy of the game doesn't know yours yet. Nothing is broken — it just needs your Firebase settings.

  1. Create a free Firebase project and turn on Realtime Database and Anonymous sign-in.
  2. Open index.html in any text editor and find the block at the very top called FIREBASE SETTINGS.
  3. Replace every YOUR_… placeholder with the values from your Firebase web app.
  4. Publish database.rules.json in the Rules tab, then save and upload the file again.

   
The full click-by-click guide is in SETUP.md. Want to just try the game on your own computer? Add ?net=local to the address to play with several tabs, no Firebase needed.
